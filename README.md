# 亚健康轻医院管理系统

> 面向「治未病 / 亚健康调理」连锁机构的业务中台 —— 一人一档、方案可追溯、核销确认收入、跨店分账、技师自动提成、经营看板实时可视。

基于 [RuoYi](https://gitee.com/y_project/RuoYi-Vue) 前后端分离框架深度定制，覆盖 **Web 管理端 + 会员移动端 + 技师移动端** 三端，围绕医疗合规与消费医疗的「获客 — 锁客 — 复购 — 连锁扩张」全链路构建。

---

## ✨ 项目亮点

- 🏥 **业务闭环**：预约 → 体质辨识 → 方案制定 → 收费开卡 → 干预核销 → 阶段复评 → 续费，复评作为强制节点。
- 💰 **合规财务**：售卡只增预收余额、核销才确认收入；赠金不可提现退款；退款自动反向冲销收入 / 提成 / 分账 / 优惠券，全程留痕可审计。
- 🔗 **连锁支撑**：总部 / 区域 / 门店 / 员工 / 客户多级数据隔离，会员跨店通用、卡项跨店核销、跨店分账结算。
- 📊 **经营看板**：总部经营板、门店运营板、财务资金板三大看板 + 首页统计大屏，收入趋势、门店排行、获客漏斗、经营预警一屏掌握。
-  **科技蓝 UI**：登录页、首屏加载、首页看板、POS 收银台统一深色科技蓝视觉（动态网格、霓虹光环、毛玻璃卡片、流光按钮）。
- 🧾 **商业收银台**：Web 端内置 POS，支持售卡开卡、到店核销、组合收款多渠道拆分、本地流水。

| **卡项与核销** | 储值卡 / 次卡 / 疗程卡 / 期限卡 / 单次订单、售卡订单、跨店核销、赠金分摊 |

| **连锁与门店** | 门店档案、门店类型（直营/加盟/联营/合作）、区域管理、价格体系、活动下发、门店考核 |

| **技师与绩效** | 技师档案、排班、服务任务、核销绑定、提成规则、业绩 / 绩效报表、客户评价 |
| **数据看板** | 总部经营板、门店运营板、财务资金板、报表导出、全链路审计留痕 |

## 🚀 快速开始

### 环境要求
- JDK 17+
- Maven 3.6+
- MySQL 5.7+ / 8.x
- Redis 5+
- Node.js 18+（前端）
- HBuilderX / 微信开发者工具（移动端，可选）

### 1. 导入数据库
`sql/` 目录按模块组织（`hc_m0_*` ~ `hc_m13_*`、`hc_p0_*`），包含建表 DDL、初始化数据、角色与菜单权限。按文件名编号顺序依次执行，或整体导入到目标库：

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p 数据库名 < sql/hc_m1_ddl.sql
# ... 依编号顺序执行其余脚本
```

> ⚠️ 含中文的脚本请以 UTF-8 方式导入，避免字符集导致乱码。

### 2. 启动后端
修改 `ruoyi-admin/src/main/resources/application*.yml` 中的 MySQL、Redis 连接信息，然后：

```bash
cd RuoYi-Vue-springboot3
mvn clean package
java -jar ruoyi-admin/target/ruoyi-admin.jar
# 默认监听 http://localhost:8080
```

### 3. 启动 Web 管理端
```bash
cd RuoYi-Vue3-master
npm install
npm run dev            # 开发，默认 http://localhost:80
npm run build:prod     # 生产打包
```

前端接口代理地址在 `vite.config.js` / `.env.*` 中配置，默认指向后端 `http://localhost:8080`。

- 默认管理员：`admin / admin123`

### 4. 移动端（可选）
使用 HBuilderX 分别打开 `hc-app-user`（会员端）与 `hc-app-tech`（技师端），在 `config.js` 中配置后端接口地址后运行到浏览器 / 模拟器 / 小程序。

## 🗄 数据库关键口径

- **实收**：售卡 / 零售的现金流入。
- **确认收入**：核销本金 + 零售确认（售卡时不确认收入）。
- **预收余额**：未核销部分，作为合同负债。
- **毛利**：确认收入 − 项目成本。

## 📝 开发说明

- 后端业务代码遵循 RuoYi 分层（Controller / Service / Mapper / Domain），业务表以 `hc_` 前缀命名。
- 金额计算使用高精度数值（BigDecimal），避免浮点误差。
- 所有资金、核销、分账、退款、调账操作均记录审计日志（操作人 / 时间 / 原值 / 新值 / 关联订单）。
- 前端 UI 主题色板见 `src/views` 各页面的 SCSS 变量（科技蓝：`#3ba9ff` / `#4dd0ff` / `#1e6fff`）。
